# VR 全景图素材来源与许可

全景漫游页（`frontend/app/vr.tsx`）使用的 360° 等距柱状投影（equirectangular，宽高比严格 2:1）
全景图，全部为真实摄影、开放授权，下载到本地由后端 `/static/legacy/` 提供，无 emoji、无运行时第三方 CDN 依赖。
主题统一为生态/自然/环境保护场景。每张均为 3840×1920（精确 2:1）JPEG。
